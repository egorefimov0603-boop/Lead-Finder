# Lead Finder MVP 0.2

Локальная система для импорта CSV из 2ГИС, хранения лидов, первичной оценки и подготовки сообщений.

## Запуск Windows
```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```
Если `py` недоступен, попробуй `python -m pip ...` и `python -m streamlit ...`.

## Импорт
1. Открой вкладку «Импорт CSV».
2. Выбери файл 2ГИС.
3. Проверь сопоставление колонок.
4. Выбери автоматическое определение ниши по рубрикам.
5. Импортируй данные.

Поддерживаются поля экспорта 2ГИС: Наименование, Рубрики, Адрес, Город, Рейтинг, Количество отзывов, Телефон, E-mail, Веб-сайт, WhatsApp, Telegram, 2GIS URL. Обрабатывается служебная первая строка `sep=,`.

База `leads.db` хранится рядом с `app.py`. Делай резервную копию перед заменой/переносом папки.

## Ограничения
Google Maps пока не подключён. Автоматическая проверка сайтов и номеров, MAX-интеграция и автоматическая рассылка не реализованы. Оценка лидов эвристическая.


## Сборка Windows EXE без установки Python на компьютере пользователя

В корне архива находится папка `.github/workflows` с автоматической сборкой для Windows.
Чтобы получить EXE, исходники нужно загрузить в GitHub-репозиторий, затем открыть вкладку
Actions и вручную запустить workflow **Build Windows EXE**. Готовая папка `LeadFinder`
появится в Artifacts запуска. Внутри будет `LeadFinder.exe` и папка `_internal` —
их нужно хранить вместе. База `leads.db` создаётся рядом с EXE.
